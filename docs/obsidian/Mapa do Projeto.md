# Mapa do Projeto — Marketing Campaign Dashboard

Esta é a porta de entrada. Todas as notas abaixo explicam o mesmo projeto, mas cada uma foca numa peça — como se você estivesse abrindo gavetas de um arquivo, uma de cada vez, sem precisar entender tudo de uma vez só.

Este projeto é um sistema para agências de marketing organizarem suas campanhas publicitárias (quanto custam, quando começam e terminam, o que já mudou nelas) em vez de usar planilhas soltas.

Toda a explicação usa a mesma analogia do início ao fim: **o projeto é como um restaurante**. Sempre que uma nota falar em "salão", "cozinha" ou "almoxarifado", é a esse restaurante que ela está se referindo.

## Por onde começar

1. [[O Problema que Resolve]] — por que esse sistema existe, antes de qualquer coisa técnica.
2. [[O Salão - Frontend]] — a parte que você vê e clica.
3. [[A Cozinha - Backend]] — quem faz o trabalho de verdade, escondido.
4. [[O Almoxarifado - Banco de Dados]] — onde tudo fica guardado permanentemente.
5. [[O Garçom - API]] — como o salão e a cozinha conversam.
6. [[Login e Segurança]] — como o sistema sabe quem é você, e protege sua senha.
7. [[Criando uma Campanha - Passo a Passo]] — o caminho completo de um clique até virar um dado salvo.
8. [[Histórico de Auditoria]] — como o sistema lembra de tudo que já mudou.
9. [[Glossário de Termos]] — todo termo técnico usado em qualquer nota, explicado em uma frase.

## Uma frase-resumo por nota

- **O Problema**: sem esse sistema, informação de campanha vive espalhada e se perde.
- **Salão**: telas, botões, formulários — o que aparece no navegador.
- **Cozinha**: o programa invisível que aplica as regras e faz os cálculos.
- **Almoxarifado**: o arquivo permanente de tudo (clientes, campanhas, usuários, histórico).
- **Garçom**: o mensageiro com uma lista fixa de pedidos que sabe entregar.
- **Login e Segurança**: como a senha é protegida e como o sistema "lembra" que você já entrou.
- **Criando uma Campanha**: um exemplo real, do clique no botão até a ficha nova no almoxarifado.
- **Histórico**: o livro de registro que anota toda mudança, com quem e quando.
- **Glossário**: dicionário rápido de termos técnicos.
